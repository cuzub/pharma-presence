# Guide d'utilisation

Votre espace est la page **Mon mois** : elle affiche votre calendrier, le résumé du mois et votre
solde d'heures.

![Page Mon mois avec le calendrier, les congés payés et le résumé du mois (données fictives)](images/employe-mon-mois.png)

- **Mon mois** : vos absences sont saisies par la pharmacienne ; une erreur ? Signalez-la-lui.
  Les **régularisations** (heures payées, récupérations…) qu'elle enregistre apparaissent en violet
  à leur date. Le résumé donne le net du mois et votre **solde cumulé** d'heures +/-.
- **Planning** : vos horaires prévus (matin et après-midi) s'affichent sous chaque date
  (« Pas présent(e) » si vous ne travaillez pas ce jour-là ; rien les jours d'absence). Ils sont
  saisis par la pharmacienne ; pour un changement, adressez-vous à elle.
- **Heures en plus / en moins** : dans *Mon mois*, cliquez sur la date → cliquez sur les **boutons
  rapides** (*+15 min*, *+30 min*, *+45 min*, *+1 h*, *−15 min*, *−30 min* ; ils s'additionnent) ou
  saisissez les minutes (`15`, `-30`) → *Enregistrer*. Pour effacer, cliquez sur la gomme (elle vide le champ, à enregistrer).
  Mêmes règles de date que pour les déplacements ci-dessous.
- **Déplacements** : dans *Mon mois*, cliquez sur la date du déplacement → *Ajouter un déplacement* → choisissez le motif
  (les kilomètres se remplissent tout seuls) → *Enregistrer*. Si la destination n'est pas dans la
  liste, choisissez « Autre » et saisissez la précision et les kilomètres. Plusieurs déplacements
  par jour sont possibles : le bouton **+** ajoute une ligne, le bouton **−** la retire (à enregistrer).
  Pour corriger ou supprimer un déplacement, cliquez sur le **crayon**.
  Vous pouvez saisir, corriger ou supprimer vos déplacements du **mois en cours**, et ceux du
  **mois précédent jusqu'au 5 inclus**. Après, le mois est clôturé : pour un oubli, adressez-vous à
  la pharmacienne.
- Pour changer votre mot de passe : cliquez sur votre nom en haut à droite.
- **Visite guidée** : un doute sur l'écran ? Cliquez sur *Visite guidée* dans le menu (ou sur le lien
  sous le calendrier) : en 5 étapes, elle vous montre où cliquer. Vous pouvez la relancer à tout moment.
